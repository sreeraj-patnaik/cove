# COVE

Local-first MVP for a private friend space. It includes a responsive PWA shell, locally persisted queued messages, Group DNA-inspired conversation UI, and interactive Echo, Afterglow and Orbit experiences.

## Run

```sh
npm install
npm run dev
```

`Queued` is intentional: this MVP has no peer transport, encryption, or central message storage, so it never misrepresents a local message as delivered.
